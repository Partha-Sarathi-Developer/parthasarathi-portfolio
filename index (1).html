GET /about

The engineer behind the endpoints

Four years, one company, three levels — from project trainee to programmer. I grew up in the codebase I now help architect.

I started at Ionixx Technologies as a project trainee in 2021 writing Spring MVC controllers, and I've spent every year since going deeper into what makes backend systems actually hold up in production.

My core is the JVM stack — Java, Spring Boot, Hibernate, JPA, MyBatis — but I'm equally at home shipping Node.js / Express services. The work that got me here was rarely glamorous: rewriting a slow MySQL query so it returns 30% faster, wiring Kafka so events stop getting lost, pushing test coverage past 80% so the next person can refactor without fear.

Why backend? Because correctness under load is a real, measurable thing. A payload either validates or it doesn't. A p95 either drops or it doesn't. I like problems that answer back.

Where I'm headed: deeper into distributed systems and system design — event-driven architectures, gRPC service meshes, and the caching and queueing layers that let a service scale without falling over. I'm also expanding into full-stack so I can own a feature end to end.
