## Run Locally

Since this is a static website, you can run it easily.

### Option 1: Open directly

Open the `index.html` file in a browser.

### Option 2: Use a local server

```bash
cd parthasarathi-portfolio
python -m http.server 8000
```

Then visit:

```bash
http://localhost:8000
```

## Project Highlights

The portfolio is intentionally designed to look like a backend dashboard, not a traditional static resume page. It uses:

- HTTP method badges

- JSON responses and request examples

This makes the portfolio feel more like a live engineering profile than a plain landing page.
